# Event Images Directory

Store local event photos in this directory. 

### How to use:
1. Place your event photo images inside this `public/events/` folder (e.g., `rvu-santhe.jpg`, `icebreaker-session.jpg`).
2. Reference them in `data/events.ts` using root-relative paths like `/events/rvu-santhe.jpg`.
3. If an image file is not found, the website will automatically display a literary placeholder.

### Default Expected Filenames:
- `/events/rvu-santhe.jpg`
- `/events/icebreaker-session.jpg`
- `/events/library-book-fair.jpg`
- `/events/chithra-kavya.jpg`
- `/events/dead-poets-society.jpg`
